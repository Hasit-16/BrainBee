Claymorphism Component Library

A premium set of colorful UI elements styled with double inner-shadows for a squishy 3D look. Perfect for kids' learning websites or fun educational tools.

1. Clay Buttons

Buttons have subtle scale reductions when clicked (`active` state) and soft translation animations on hover to invite interaction.

3. Form & Text Inputs

Form inputs are built with an inset shadow. On focus, they acquire a soft outline highlight that mimics colored clay borders.

Standard Text Input

HTML 
<div class="clay-input-wrapper">
  <label class="clay-label" for="std-input">What's your name?</label>
  <input type="text" class="clay-input" id="std-input" placeholder="Type name here...">
</div>

Clay Textarea

HTML 
<div class="clay-input-wrapper">
  <label class="clay-label" for="area-input">Write a funny story!</label>
  <textarea class="clay-input clay-textarea" id="area-input" placeholder="Once upon..."></textarea>
</div>

4. Switches, Checkboxes, and Sliders

Small controls styled with clay properties make configurations like volume, difficulty levels, or avatar selections easy and tactile.

Toggle Switch

HTML 
<label class="clay-switch">
  <input type="checkbox" class="clay-switch-input" checked>
  <span class="clay-switch-track">
    <span class="clay-switch-thumb"></span>
  </span>
  <span style="font-weight: 700;">Sound FX</span>
</label>

Tactile Checkbox

HTML 
<label class="clay-checkbox-label">
  <input type="checkbox" class="clay-checkbox-input" checked>
  <span class="clay-checkbox-box"></span>
  <span>Music Active</span>
</label>

Clay Radio Option

HTML 
<label class="clay-radio-label">
